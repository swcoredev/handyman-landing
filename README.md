# Handyman - Landing Page для вызова мастера на дом

Современный, красивый и отзывчивый landing page для сервиса вызова мастера на дом.

## ✨ Особенности

- 🎨 **Современный дизайн** - использование градиентов, плавных анимаций и современных UI паттернов
- 📱 **Адаптивный дизайн** - отлично выглядит на всех устройствах
- ⚡ **Быстрая загрузка** - оптимизированный код без тяжелых зависимостей
- 🎭 **Плавные анимации** - микро-взаимодействия для улучшения UX
- 📋 **Форма заказа** - интуитивная форма для связи с клиентами
- 💬 **Секция отзывов** - социальное доказательство качества услуг

## 🚀 Запуск проекта

Проект не требует установки зависимостей. Просто откройте `index.html` в браузере:

```bash
# Вариант 1: Открыть напрямую
open index.html

# Вариант 2: Запустить локальный сервер (рекомендуется)
python3 -m http.server 8000
# Затем откройте http://localhost:8000

# Вариант 3: Использовать Live Server (VS Code)
# Установите расширение Live Server и нажмите "Go Live"
```

## 🎨 Дизайн-система

### Цветовая палитра
- **Primary**: `hsl(215, 100%, 50%)` - основной синий
- **Secondary**: `hsl(45, 100%, 55%)` - акцентный жёлтый
- **Text**: `hsl(220, 20%, 10%)` - основной текст
- **Background**: Градиенты и светлые тона

### Типография
- **Шрифт**: Inter (Google Fonts)
- **Размеры**: от 0.75rem до 3rem
- **Веса**: 300, 400, 600, 700, 800

### Анимации
- Плавные переходы (150ms - 500ms)
- Hover-эффекты на карточках
- Floating анимации для hero-карточек
- Scroll-анимации для появления элементов

## 🛠️ Настройка

### Изменение контактной информации

Отредактируйте секцию контактов в `index.html`:

```html
<div class="contact-value">+7 (999) 123-45-67</div>
<div class="contact-value">info@handyman.ru</div>
```

### Изменение цветовой схемы

Обновите CSS переменные в `styles.css`:

```css
:root {
    --primary-color: hsl(215, 100%, 50%);
    --secondary-color: hsl(45, 100%, 55%);
    /* ... */
}
```

### Подключение формы к API

Отредактируйте обработчик формы в `script.js`:

```javascript
// Замените симуляцию на реальный API запрос
const response = await fetch('YOUR_API_ENDPOINT', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data)
});
```
